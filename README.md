# Recipe Matcher & Baking Scaler

A full-stack web application that helps home bakers find recipes based on ingredients they already have and scale ingredient quantities to their desired serving sizes. Built with Java, Spring Boot, PostgreSQL, and JavaScript, the application is containerized with Docker and deployed on AWS EC2 with Nginx and HTTPS.

**Features**

- **Ingredient Matching:** Find baking recipes based on available pantry ingredients.
- **Recipe Scaling:** Dynamically adjust ingredient quantities for different serving sizes.
- **Recipe Categories:** Explore curated recipes for bread, cakes, shortbreads, and quick breads.
- **Cloud Deployment:** Access the application through a secure HTTPS connection.

**Tech Stack:** Java 17+, Spring Boot, Spring Data JPA, PostgreSQL, HTML, Tailwind CSS, JavaScript, Docker, Docker Compose, AWS EC2, Nginx, Let's Encrypt, and Git.
